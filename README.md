# 🚗 CarCatalog

CarCatalog est une application web dynamique et responsive permettant de gérer un catalogue de voitures et de marques via une interface administrateur sécurisée. Elle a été réalisée dans le cadre d’une évaluation technique autour du concept de CRUD (Create, Read, Update, Delete).

## 📌 Fonctionnalités

🔐 **Authentification**  
- Accès sécurisé à l’espace administrateur via une connexion dédiée (distincte des utilisateurs clients).

🛠️ **CRUD Marque**  
- Créer, lire, mettre à jour et supprimer des marques de voitures.

🚙 **CRUD Voiture**  
- Créer, lire, mettre à jour et supprimer des voitures associées à une marque.

📡 **API**  
- Développée avec **Laravel** (PHP), l’API permet de gérer toutes les opérations CRUD pour les entités `Marque` et `Voiture`.

🗃️ **Base de données relationnelle**  
- Utilisation de **MySQL**, avec au moins 10 enregistrements insérés par défaut.

🎨 **Interface utilisateur**  
- Front-end en **HTML5**, **CSS3** et **JavaScript** pour une interaction fluide avec l’API.
- Design responsive, accessible depuis desktop et mobile.
